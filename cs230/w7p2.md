## Input

The program asks for the file's name once, with the prompt `"File name: "`, then reads the file with that name.

If there is no file with that name, the program prints `Could not open missing.csv.`, with the name that was typed in place of `missing.csv`, and ends. It prints nothing else and does not ask for another name.

The file's first line is a header that names the columns. Every line after it is a name, then that student's scores, separated by commas:

```
name,test1,test2,test3
Ada,90,85,92
Grace,78,abc,88
Alan,100,95,98
Linus,70,75
Barbara,65,58,61
```

A student can have any number of scores: Linus missed a test, so his line has two. A score is a whole number, and spaces around it are fine, so `Ada, 90, 85` is a usable line. You can assume every line after the header has a name and at least one score, and that the file has no blank lines.

## Processing

- `letter_grade(score)`
  - Takes an average and returns `"A"` for 90 and above, `"B"` for 80 and above, `"C"` for 70 and above, `"D"` for 60 and above, and `"F"` below 60. It prints nothing.
- `parse_line(line)`
  - Takes one line of the file and returns two values: the student's name and the average of their scores. `parse_line("Ada,90,85,92\n")` returns `("Ada", 89.0)`. It prints nothing and has no `try`.
    - Hint: [Lines with Fields](https://bi3mer.github.io/lectures/cs230/10-exceptions-and-files.html#27).
- `print_report(filename)`
  - Opens the file with `with open(...)`, skips the header with `readline()`, and prints one line per student with a `for` loop, as in [We Do: Total Sales](https://bi3mer.github.io/lectures/cs230/10-exceptions-and-files.html#30).
  - Calls `parse_line` inside a `try`, and catches the `ValueError` for a score that is not a whole number, which skips that line and goes on to the next.
- `main()`
  - Takes no parameters. Asks for the file's name and calls `print_report` with it inside a `try`.
  - Catches the `FileNotFoundError` that `open()` in `print_report` raises for a file that does not exist, and prints `Could not open missing.csv.`

Each `except` names the exception it catches.

_Question: Neither `parse_line` nor `print_report` has a `try` around the line that fails. Which function catches each exception, and how does the error get there?_

## Output

One line per line of the file after the header, in the same order. A student prints as their name, a colon, their average with two digits after the decimal point, and their letter grade in parentheses: `Ada: 89.00 (B)`. A skipped line prints as `Skipped: ` and the line. A file with no students prints nothing after the prompt, and a file that does not exist prints only the `Could not open` line.
