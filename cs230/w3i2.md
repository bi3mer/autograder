# Week 3 - In-Class Activity 2: FizzBuzz

FizzBuzz is a classic programming interview problem to see if the interviewee can do even the simplest of programming tasks. Given a number, the program outputs the numbers from 1 to that number. If, though, the number is a multiple of 3, then it outputs "Fizz" instead of the number. If the number is a multiple of 5, it outputs "Buzz" instead. If the number is a multiple of both 3 and 5, then it outputs "FizzBuzz."

## Input

Prompt the user with: `"Enter a positive whole number: "`

A valid answer is a whole number of 1 or more. If the user enters 0 or a negative number, ask the same question again, as many times as it takes, until the user enters a positive number. You do not have to handle anything that is not a whole number.

## Processing

- Use a `while` loop to keep asking until the number is positive
- Use [`int()`](https://www.w3schools.com/python/ref_func_int.asp) to turn the user's answer into a number
- Use a `for` loop to go through the numbers
- Hint: you can check if a number is a multiple of another with `%`
- Hint: you need to order your if/elif/else chain well or you may print out "Fizz" when you should output "FizzBuzz"

## Output

Once the loop ends, print one line for every number from 1 up to and including the user's number:

- A multiple of both 3 and 5 prints `FizzBuzz`
- A multiple of 3 prints `Fizz`
- A multiple of 5 prints `Buzz`
- Any other number prints the number itself
