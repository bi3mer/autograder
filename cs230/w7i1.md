# Week 7 - In-Class Activity 1: Drop the Lowest

Some courses drop each student's lowest quiz score before working out the grade. This program reads quiz scores, then shows the scores as they were entered and the scores that still count. `read_scores` collects the scores into a list, and `drop_lowest` builds a new list without the lowest one. `drop_lowest` must leave the list it was given unchanged: the program prints that list after calling it, so any change shows up in the output.

## Input

The program asks for one score at a time with the prompt `"Score: "`. You can assume each answer is a whole number, so there is nothing to validate. A blank answer ends the input.

## Processing

- `read_scores()`
  - Takes no parameters.
  - Starts with an empty list, then asks for scores again and again until the answer is blank.
  - Converts each score with `int()` before adding it to the end of the list.
    - Hint: this is [Collect Scores](https://bi3mer.github.io/lectures/cs230/08-lists.html#13) from class 8.
  - Returns the list.
- `drop_lowest(scores)`
  - Takes one parameter, the list of scores.
  - Returns a new list holding every score except the lowest one, in order from lowest to highest. `drop_lowest([90, 72, 85])` returns `[85, 90]`.
  - If the lowest score appears more than once, only one of them is dropped. `drop_lowest([70, 80, 70])` returns `[70, 80]`.
  - If `scores` is empty, returns an empty list.
    - Hint: what do `min()` and `pop()` do with an empty list?
  - Leaves `scores` unchanged: no item removed, added, or moved.
    - Hint: `b = a` does not copy a list. `copy()` and `sorted()` both give you a new list of your own to change.
- Neither function prints anything. Each one hands its answer back with `return`, and the last lines of the program print it.

## Output

End the program with these four lines, below the functions:

```python
scores = read_scores()
kept = drop_lowest(scores)
print(f"Entered: {scores}")
print(f"Kept: {kept}")
```

After the prompts, the program prints two lines: the scores in the order they were entered, then the scores that count. Both lines print after `drop_lowest` runs, so if `drop_lowest` changes `scores`, the `Entered` line shows it.

## Examples

```
Score: 90
Score: 72
Score: 85
Score: 100
Score:
Entered: [90, 72, 85, 100]
Kept: [85, 90, 100]
```

Two scores tie for lowest, and only one of them is dropped:

```
Score: 70
Score: 80
Score: 70
Score:
Entered: [70, 80, 70]
Kept: [70, 80]
```

With one score, nothing is left after the lowest is dropped:

```
Score: 95
Score:
Entered: [95]
Kept: []
```

A blank answer right away means no scores at all:

```
Score:
Entered: []
Kept: []
```
