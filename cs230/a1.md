Most of us drink coffee, and it can be illuminating to see how much it costs per year. The same is true for every habit, whether it is daily, weekly, monthly, etc. This assignment is going to help you understand exactly how much a habit costs you per year.

## Program Behavior

### Input

You need to ask the user for the following:

1. Name of the habit (e.g. drinking coffee)
2. Percent of days per year you indulge in the habit between 0 and 100 (e.g. if you drink coffee every day, enter 100)
3. How much it costs before tax (e.g., a grande iced coffee from _Starbucks_ in Waltham costs $3.95 before tax and $4.23 after.)

See examples below for the exact prompt that you should use.

### Processing

You need to calculate the following:

1. How much the user spends per day on the habit and how much goes to taxes
2. How much the user spends per month on the habit and how much goes to taxes
3. How much the user spends per year on the habit and how much goes to taxes

Assume a tax rate of 7.00\%.

### Output

```
Habit Costs for [HABIT HERE]
  Spend per day:
    Pre tax	$X.XX
    Tax	$X.XX
    Total	$X.XX

  Spend per month:
    Pre tax	$X.XX
    Tax	$X.XX
    Total	$X.XX

  Spend per year:
    Pre tax	$X.XX
    Tax	$X.XX
    Total	$X.XX
```

## Notes

- Use symbolic constants where appropriate.
- Your program must open with a docstring (`"""..."""`) as its very first statement, before any other code
- There are 365 days in a year.
- There are 12 months per year.
- Tax rate is 0.07
- Output should include two decimal places (e.g. `1` should output as `1.00` (`round` is not the correct function to use for this, use an **f-string**))
- Output format:
  - Spaces before each label (e.g. two spaces before `Spend per day:` and four spaces before `Pre tax`)
  - A tab (`\t`) after each label and before its value
  - Depending on your OS and configuration, the output may line up nicely like the examples above, or it may look a little gross with the value for `Tax` not lining up with the others
- Notice that there is an empty line (`\n`) between the program's input and output
- Output must match the examples
- Assume valid input (e.g. the user could enter a -100 for percent of days, but your program does not need to handle this)
