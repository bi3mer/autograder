# Week 7 - Problem 1: To-Do List

A to-do list keeps tasks in order. New tasks go on the end, urgent ones jump to the front, and finished ones come off. This program keeps one list of tasks and changes it as the user types commands, until the user enters a blank command.

The program is three functions. `print_tasks` shows the list. `finish_task` takes one task off the list. `main` reads each command and does what it asks.

## Input

Every command is read with the prompt `"Command: "`. A blank command ends the program. The commands are lowercase words:

| Command | What it does                                                                                       |
| ------- | -------------------------------------------------------------------------------------------------- |
| `add`   | Asks for a task with the prompt `"Task: "`, then adds it to the end of the list.                   |
| `first` | Asks for a task with the prompt `"Task: "`, then adds it to the front of the list.                 |
| `done`  | Asks for a task number with the prompt `"Number: "`, then takes that task off. Task 1 is the first. |
| `list`  | Prints the list.                                                                                   |

Any other command prints `Unknown command.` and the program asks for the next command. A task can be any text, including spaces and digits.

## Processing

- `print_tasks(tasks)`
  - Prints the tasks, numbered from 1.
- `finish_task(tasks, text)`
  - Takes the list of tasks and the text typed at the `"Number: "` prompt, and takes that task off the list with `pop()`.
  - Text that is not a whole number, or a number with no task, leaves the list as it was.
  - Changes the list itself and returns nothing, like `curve` in [We Do: Curve the Scores](https://bi3mer.github.io/lectures/cs230/09-changing-lists.html#21).
- `main()`
  - Takes no parameters. Starts with an empty list and asks for commands until the command is blank.
  - Uses `append()` for `add`, `insert()` for `first`, `print_tasks` for `list`, and `finish_task` for `done`.

Each `except` names the exception it catches.

_Review for quiz: `finish_task` returns nothing. Why does `main` still see the task disappear from the list?_

## Output

Each `done` prints one line: `Done: Buy milk`, `Not a task number.`, or `There is no task 9.` Each `list` prints the numbered tasks or `Nothing to do.` The last line is `Tasks left: 2`.
