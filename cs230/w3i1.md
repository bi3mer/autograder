# Week 3 - In-Class Activity 1: Greeting at the Door

Let's write a program for a door that greets people. It can't recognize people, so it has to ask them whether they are an employee, store member, or a guest. Even worse, it won't let anyone by until they've told the door which of the three they are.

## Input

Prompt the user with: `"Employee (E), Member (M), or Other (O)? "`

Six answers are valid: `E`, `e`, `M`, `m`, `O`, and `o`. Anything else is invalid, and the door asks the same question again, as many times as it takes, until the user enters one of the six.

## Processing

- Use a while loop to validate that the user's input is correct
- You can handle the requirement of upper and lower cases either with two cases (e.g. `variable == 'e' or variable == 'E'`) or by using [`.upper()`](https://www.w3schools.com/python/ref_string_upper.asp) or [`.lower()`](https://www.w3schools.com/python/ref_string_lower.asp).
- For matching the letter to the output, use a [`match` statement](https://www.w3schools.com/python/python_match.asp).

## Output

Once the loop ends, print one line for the answer you ended up with:

- `"E"` prints `"Welcome, Employee!"`
- `"M"` prints `"Welcome, Member!"`
- `"O"` prints `"Welcome, Guest!"`

## Examples

```
Employee (E), Member (M), or Other (O)? m
Welcome, Member!
```

```
Employee (E), Member (M), or Other (O)? Employee
Employee (E), Member (M), or Other (O)? EM
Employee (E), Member (M), or Other (O)? E
Welcome, Employee!
```

```
Employee (E), Member (M), or Other (O)? o
Welcome, Guest!
```
