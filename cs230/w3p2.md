# Week 3 - Problem 2: Calculate the Sum From 1 to N

The user gives you a number, and you have to calculate the sum from 1 to N. For example, if they gave you three, you have to calculate 1 + 2 + 3 = 6. Some of you who have taken discrete mathematics know that this can be calculated with [Gauss's Summation](https://en.wikipedia.org/wiki/Gauss_sum), but don't cheat (please). Use a loop to add the numbers one at a time instead of the formula `n * (n + 1) / 2` — the point of this exercise is practicing loops, not the shortcut.

## Input

Prompt the user for one integer:

- `"Enter a positive number: "`

## Processing

- If the number the user entered is 0 or less, reprompt them with the same prompt (`"Enter a positive number: "`) until they enter a number greater than 0. You can assume that the user will always enter a valid integer.
- Starting from 0, add 1, then 2, then 3, and so on, up to and including N, using a loop.
- You must use a `for` loop to compute the sum. A `while` loop will not receive credit for the summing loop, even if the output is correct. (The reprompt above is a separate loop, and is not restricted to a particular kind — a `while` loop is the natural fit there.)

## Output

Output the sum:

- Output string: `"Sum: "`

## Examples

```
Enter a positive number: 3
Sum: 6
```

```
Enter a positive number: 1
Sum: 1
```

```
Enter a positive number: 0
Enter a positive number: 3
Sum: 6
```

```
Enter a positive number: -2
Enter a positive number: 3
Sum: 6
```
