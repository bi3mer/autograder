# Week 3 - Problem 1: Yes or No?

A common problem we have already run into is validating the user input to be something simple, like yes or no. What you need to do is right a loop that continuously prompts the user for `"yes"` or `"no"` until they have input one of those two. Once that is done, output "The user said yes." or "The user said no." (Hint: you should not need an `if` for the output.)

## Input

Prompt the user for one string with `"Yes or no?"`.

## Processing

Do not allow the user to proceed until they have entered `"yes"` or `"no"`. You do not need to support capitalized versions like `"YEs"` etc.

You must use a `while` loop to do this. A `for` loop will not receive credit, even if the output is correct.

## Output

- If the user entered "yes", output "The user said yes."
- If the user entered "no", output "The user said no."

## Examples

```
Yes or no? n
Yes or no? NO
Yes or no? nO
Yes or no? I said no!
Yes or no? no
The user said no.
```
