# Week 5 - In-Class Activity 2: Palindrome

A palindrome is a word that reads the same forwards and backwards, like `racecar`, `noon`, or `level`. This program checks words with two functions. `reverse_string` turns a word around, and `is_palindrome` decides whether the word is a palindrome. `is_palindrome` never reverses anything itself: it calls `reverse_string` and compares what comes back with the word it was given.

## Input

The program asks for one word with the prompt `"Word: "`. Any text is allowed, including capital letters, spaces, and digits, so there is nothing to validate.

## Processing

- `reverse_string(word)`
  - Takes one parameter, the word.
  - Builds a new string holding the characters of `word` in the opposite order, one character at a time in a loop, and returns it. `reverse_string("hello")` returns `"olleh"`.
    - Hint: start with an empty string and loop with `for i in range(len(word))`. If each character goes on the **front** of the new string instead of the back, what order do they end up in?
  - Python already has a built-in function named `reversed()`. You may not use it here, because this activity is about writing the loop yourself.
- `is_palindrome(word)`
  - Takes one parameter, the word.
  - Calls `reverse_string(word)`, then returns `True` if the reversed word is the same as `word` and `False` if it is not.
- Neither function prints anything or calls `input()`. Each one hands its answer back with `return`, and the last lines of the program print it.

Every character counts exactly as typed. `Racecar` is not a palindrome, because `R` and `r` are different characters. `taco cat` is not one either: its reverse is `tac ocat`, since the space is a character too.

## Output

Leave two blank lines between the two functions and two after the second one (flake8 counts fewer as a finding), then end the program with these three lines:

```python
word = input("Word: ")
print(reverse_string(word))
print(is_palindrome(word))
```

After the prompt, the program prints two lines: the word reversed, then `True` or `False`.

## Examples

```
Word: racecar
racecar
True
```

```
Word: hello
olleh
False
```

The capital `R` makes this word different from its reverse:

```
Word: Racecar
racecaR
False
```

The space moves when the word is reversed:

```
Word: taco cat
tac ocat
False
```
