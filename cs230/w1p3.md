# Week 1 - Problem 3: Pythagorean Theorem

Write a program that solves for the hypotenuse of a right triangle. Given the two legs `a` and `b`, the Pythagorean theorem says that `a**2 + b**2 = c**2`, where `c` is the hypotenuse. The user gives you `a` and `b`, and your program solves for `c` and for `c**2`.

## Input

Prompt the user for two values:

- **a**: the length of the first leg (allow decimal values, e.g. 1.5)
- **b**: the length of the second leg (allow decimal values)

## Processing

- Square each leg and add the two squares together. That sum is `c**2`.
- Take the square root of that sum to get `c`. Python has no square-root operator, so raise the sum to the power of one half: `(a ** 2 + b ** 2) ** 0.5`. `math.sqrt` also works if you would rather `import math`.

## Output

Print `c` first, then `c` squared on separate lines (see below). Make sure to use an [f-string](https://www.geeksforgeeks.org/python/formatted-string-literals-f-strings-python/) and display 4 decimals with the f-string.

## Examples

```
Enter side a: 3
Enter side b: 4
c = 5.0000
c^2 = 25.0000
```

```
Enter side a: 1.5
Enter side b: 2.5
c = 2.9155
c^2 = 8.5000
```

```
Enter side a: 2
Enter side b: 3
c = 3.6056
c^2 = 13.0000
```
