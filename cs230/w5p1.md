# Week 5 - Problem 1: Guess the Number

Let's write a guessing game. The program picks a secret number from 1 to 100, and the player guesses until they find it. After each wrong guess, the program says whether the guess was too high or too low.

The program is two functions. `get_positive_number` asks for a number and keeps asking until the answer is a whole number above 0. `play_game` runs the game, calling `get_positive_number` in a loop to read each guess.

## Starter Code

Your program starts and ends with these lines. Replace the comment with your two functions:

```python
import random


# get_positive_number and play_game go here


secret = random.randint(1, 100)
play_game(secret)
```

`import random` loads Python's random-number tools, and `random.randint(1, 100)` picks a whole number from 1 to 100, so every game has a new secret. **Do not** change these lines. (Note: flake8 wants two blank lines between `import random` and the definition of the first function `get_positive_number`.)

## Input

Every guess the program reads goes through `get_positive_number`, with the prompt `"Guess: "`.

A valid answer is a whole number above 0, typed with digits only. `5`, `42`, and `100` are valid. `0`, `-4`, `3.5`, `abc`, an empty answer, and `5` with a space before it are not. If the answer is invalid, ask the same question again, as many times as it takes, until the answer is valid.

_Review for quiz: Why should this be a `while` loop instead of a `for` loop?_

## Processing

- `get_positive_number(prompt)`
  - Prompt the user with `prompt` until the user has input a valid integer that is positive. Return that integer.
    - Hint: You need to handle invalid input like "1a!2" by re-prompting. What did we learn in class which can check if characters in a string are numbers?
    - Hint-Answer: [`isdigit()`](https://www.w3schools.com/python/ref_string_isdigit.asp) before converting it with `int()`. `int("abc")` crashes, and `isdigit()` is how you know it will not.
  - Returns the user input as an integer
    - Hint: `int(user_input)`

- `play_game(secret)`:
  - Takes one parameter, the secret number.
  - Loop until the user guesses the secret number.
    - You should use `get_positive_number` to get the user's guess.
    - If the guess is higher than the secret number, output `"Too high."`
    - If the guess is lower than the secret number, output `"Too low."`
    - If correct, the loop should end and then output `"Correct"`.

## Output

After each wrong guess, `play_game` prints one line:

- `Too high.` when the guess is above the secret
- `Too low.` when the guess is below the secret

When the guess equals the secret, it prints `Correct!` and the game ends. An invalid answer gets no message: the same prompt simply appears again.

Leave two blank lines after `import random`, between the two functions, and after the second one. flake8 counts fewer as a finding.
