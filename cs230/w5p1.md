# Week 5 - Problem 1: Guess the Number

Let's write a two-player guessing game. Player one types a secret number from 1 to 100 while player two looks away, and then player two guesses until they find it. After each wrong guess, the program says whether the guess was too high or too low.

The program is two functions. `get_positive_number` asks for a number and keeps asking until the answer is a whole number above 0. `play_game` runs the game, calling `get_positive_number` in a loop to read each guess.

## Input

Every number the program reads goes through `get_positive_number`, with one of two prompts:

- The secret: `"Secret number: "`
- Each guess: `"Guess: "`

A valid answer is a whole number above 0, typed with digits only. `5`, `42`, and `100` are valid. `0`, `-4`, `3.5`, `abc`, an empty answer, and `5` with a space before it are not. If the answer is invalid, ask the same question again, as many times as it takes, until the answer is valid.

## Processing

`get_positive_number(prompt)`:

- Takes one parameter, the prompt to show, and asks with `input(prompt)`.
- Loops until the answer is valid.
- Checks the answer with [`isdigit()`](https://www.w3schools.com/python/ref_string_isdigit.asp) before converting it with `int()`. `int("abc")` crashes, and `isdigit()` is how you know it will not.
- Returns the number as an `int`.

`play_game(secret)`:

- Takes one parameter, the secret number.
- Loops until the guess equals the secret, reading each guess with `get_positive_number("Guess: ")`.

## Output

After each wrong guess, `play_game` prints one line:

- `Too high.` when the guess is above the secret
- `Too low.` when the guess is below the secret

When the guess equals the secret, it prints `Correct!` and the game ends. An invalid answer gets no message: the same prompt simply appears again.

Leave two blank lines between the two functions and two more after the second one (flake8 counts fewer as a finding), then end the program with these lines, which read the secret and start the game:

```python
secret = get_positive_number("Secret number: ")
play_game(secret)
```
