# Week 6 - In-Class Activity 1: Sign-In Sheet

A sign-in sheet collects everyone's name as they arrive. This program does it with one function, `read_names`, which asks each person for a first name and a last name. It keeps the names in two lists, one for first names and one for last names, and returns both lists at once.

## Input

Each person answers two prompts, in this order: `"What is your first name? "` and then `"What is your last name? "`. You can assume each answer is a single word.

A blank answer to either prompt ends the sign-in. If someone types a first name and then leaves the last name blank, that person is not added at all: their first name stays off the list too.

## Processing

- `read_names()`
  - Takes no parameters.
  - Starts with two empty lists, one for first names and one for last names. Name them whatever you like.
  - Asks for a first name and then a last name, again and again, until one of them is blank.
  - Stores each name with its first letter uppercase and every other letter lowercase: `ada` is stored as `Ada`, and `HOPPER` as `Hopper`.
    - Hint: one of the string methods from week 4 does this in a single call. Look through the [string cheat sheet](https://bi3mer.github.io/lectures/cs230/string-cheatsheet.html).
  - Adds each first name to the end of the first-name list, and each last name to the end of the last-name list.
    - Hint: when can you be sure that a first name belongs on the list?
  - Returns both lists, separated by a comma: `return first_list, last_list`, with your own names for the two lists.
- `read_names` does not print anything. The last lines of the program print the lists.

## Output

End the program with these three lines, below the function:

```python
first_names, last_names = read_names()
print(first_names)
print(last_names)
```

`read_names` hands back two lists, and the first line unpacks them into two variables, the same way `a, b = ...` unpacked [two returned values](https://bi3mer.github.io/lectures/cs230/07-functions.html#84) in week 5.

After the prompts, the program prints two lines: the list of first names, then the list of last names.

## Examples

```
What is your first name? ada
What is your last name? lovelace
What is your first name? grace
What is your last name? hopper
What is your first name?
['Ada', 'Grace']
['Lovelace', 'Hopper']
```

Katherine's last name is blank, so the sign-in ends and Katherine is not added:

```
What is your first name? alan
What is your last name? turing
What is your first name? katherine
What is your last name?
['Alan']
['Turing']
```

Every name is stored with only its first letter uppercase, however it was typed:

```
What is your first name? gRACE
What is your last name? HOPPER
What is your first name? ADA
What is your last name? lovelace
What is your first name?
['Grace', 'Ada']
['Hopper', 'Lovelace']
```
