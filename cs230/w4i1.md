# Week 4 - In-Class Activity 1: Spell It Out

Let's write a program that spells a string out vertically. The user types a string, and the program prints it back one character per line, in order. It insists on getting at least one character: if the user presses Enter without typing anything, it asks again.

## Input

Prompt the user with: `"Enter a string: "`

A valid answer has at least one character. If the user presses Enter without typing anything, ask the same question again, as many times as it takes, until the user enters at least one character.

## Processing

- Loop until the user enters a string that has at least one character
- Loop over the positions in the string and print the character at each position
- Hint: [`len()`](https://www.w3schools.com/python/ref_func_len.asp) gives the number of characters in a string

## Output

Once the loop ends, print one line for every character in the string, in the order they appear. Every character counts: letters, digits, punctuation, all of them.

## Examples

```
Enter a string: hello
h
e
l
l
o
```

Here the user pressed Enter without typing anything the first time, so the question was asked again:

```
Enter a string:
Enter a string: CS230!
C
S
2
3
0
!
```

```
Enter a string: a
a
```
