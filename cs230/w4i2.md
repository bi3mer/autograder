# Week 4 - In-Class Activity 2: Find It

Python strings come with a `find()` method. `"banana".find("nan")` is `2`, because `nan` starts at position 2 of `banana` (positions count from 0, like the indexes in the last activity), and `"banana".find("xyz")` is `-1`, because `xyz` is nowhere in `banana`. In this activity you write `find()` yourself. Calling `find()` instead defeats the point, so a submission that calls it scores zero, the same as one with a syntax error.

## Starter Code

Start from this program. It only answers _whether_ the substring is in the word, and it takes whatever the user types:

```python
word = input("Enter a word: ")
substring = input("Enter a substring: ")
found = False

for i in range(len(word) - len(substring) + 1):
    candidate = ""
    for j in range(len(substring)):
        candidate += word[i + j]

    if candidate == substring:
        found = True
        break

print(found)
```

Run it with `banana` and `nan` and it prints `True`; with `banana` and `xyz` it prints `False`. Read it before you change it: work out what `i`, `j`, and `candidate` are at each step when `word` is `banana` and `substring` is `nan`.

## Input

Prompt the user with: `"Enter a word: "` and then `"Enter a substring: "`

A valid word has at least one character. A valid substring has at least one character and is no longer than the word. If an answer is not valid, ask the same question again, as many times as it takes, until it is. Ask for the word first, and only move on to the substring once the word is valid; a rejected substring re-asks for the substring only.

## Processing

- Loop until the user enters a valid word, then loop until the user enters a valid substring
- Instead of remembering _whether_ the substring was found, remember _where_
- Hint: [`len()`](https://www.w3schools.com/python/ref_func_len.asp) gives the number of characters in a string, which is all the validation needs
- Hint: `-1` is not a position in any string, which is what makes it a good answer for "not found"

## Output

Once both answers are valid, print one line: the position where `substring` first appears in `word`, or `-1` if it does not appear anywhere. Positions start at `0`. If the substring appears more than once, print the first position.

## Examples

```
Enter a word: banana
Enter a substring: nan
2
```

```
Enter a word: banana
Enter a substring: xyz
-1
```

`a` appears three times in `banana`, at positions 1, 3, and 5. The first one wins:

```
Enter a word: banana
Enter a substring: a

```

Here the user pressed Enter without typing a word, and then the substring `bananas` was rejected for being longer than the word, so each question was asked again:

```
Enter a word:
Enter a word: banana
Enter a substring: bananas
Enter a substring: ban
0
```
