# Week 1 - Problem 2: Parking Fee

Write a program that calculates a parking garage fee.

## Input

Prompt the user for one value:

- **hours**: the number of hours parked (allow decimal values, e.g. 2.5 hours)
  - The prompt should be `"Enter hours parked: "` (note the trailing space)

## Processing

- The fee is a flat 5 plus the number of hours parked multiplied by 2.5 (i.e. `5 + hours * 2.5`)
- The fee **cannot exceed $20**, no matter how many hours are parked.
- Use the `format` function to format the fee to **2 decimal places**

## Output

Print the parking fee:

- Parking fee
  - Output string: `"Parking fee: $"`

The line has a single space between the output string and the value, as shown in the examples below.

## Example

```
Enter hours parked: 2.5
Parking fee: $ 11.25
```

```
Enter hours parked: 10
Parking fee: $ 20.00
```
