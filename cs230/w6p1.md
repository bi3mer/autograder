# Week 6 - Problem 1: Vote Counter

Let's count a vote. Each person types their choice, and the voting ends when someone enters a blank vote. The program then prints the share of the votes each choice got, as a percentage, and which choice won.

The program is two functions. `read_votes` collects the votes into a list. `print_results` works out the results from that list and prints them.

## Starter Code

Your program ends with these two lines. Put your two functions above them:

```python
votes = read_votes()
print_results(votes)
```

## Input

Every vote is read by `read_votes`, with the prompt `"Vote: "`. A vote can be any text, including more than one word, like `ice cream`. You can assume each choice is typed the same way every time: `pizza` is always `pizza`, never `Pizza`, and never with extra spaces around it.

A blank vote ends the voting, and it is not a vote itself.

## Processing

- `read_votes()`
  - Takes no parameters.
  - Asks for votes until the vote is blank, adding each vote to the end of a list.
  - Returns the list. It prints nothing.
- `print_results(votes)`
  - Takes one parameter, the list of votes.
  - If the list is empty, prints `No votes.` and nothing else.
  - Otherwise, prints one line for each choice, in the order each choice got its first vote, then one line for the winner.
    - Hint: start by building a second list that holds each choice once. How can you tell whether a choice is already in that list?
    - Hint: then count one choice at a time. For each choice, how many of the votes match it?
  - A choice's percentage is its number of votes divided by the total number of votes, times 100, shown with one digit after the decimal point: `f"{percent:.1f}"`.
  - The winner is the choice with the most votes. If two or more choices tie for the most, the winner is the one that got its first vote earliest.

_Review for quiz: why does `print_results` need a list of the choices, instead of only looping over `votes`?_

## Output

Each choice prints as its name, a colon, and its percentage with a `%` sign, like `pizza: 50.0%`. The last line is `Winner: ` followed by the winning choice.

## Examples

Pizza got three of the six votes, so it gets 50.0% and wins:

```
Vote: pizza
Vote: tacos
Vote: pizza
Vote: sushi
Vote: pizza
Vote: sushi
Vote:
pizza: 50.0%
tacos: 16.7%
sushi: 33.3%
Winner: pizza
```

Tacos and pizza tie with two votes each. Tacos got its first vote earlier, so tacos wins:

```
Vote: tacos
Vote: pizza
Vote: pizza
Vote: tacos
Vote:
tacos: 50.0%
pizza: 50.0%
Winner: tacos
```

No one voted:

```
Vote:
No votes.
```
