# Week 2 - Problem 1: Discounts

Write a program that calculates the price and discount for store members and store employees, with an additional discount if the total price, pre-discount, is at least $10,000.

## Input

Prompt the user for:

- **Price** - get a number from the user which represents how much they spent. Don't worry about taxes or stuff like that.
  - Should this be a `float` or an `integer`?
  - The prompt should be `"How much did you spend? "` (note the trailing space)
- **Membership Type** - get the membership type from the user:
  - "e" - employee
  - "m" - member
  - otherwise, the user is not a store member and is not a store employee.
  - The prompt should be `"Employee (e), member (m), or Enter to skip: "` (note the trailing space)
  - In addition, I want you to include the beginnings of handling unexpected input. In this case, what if the user enters "E" instead of "e"? Same with "M" instead of "m"? Your program should handle this. Hint: you can either modify the character (make it upper case (`.upper`) or lower case (`.lower`)) or you can handle both cases with logical operators.

## Processing

- Store employees get a 30% discount (should 30% be a constant?)
- Store members get a 10% discount (should 10% be a constant?)
- If the total price, pre-discount, is at least $10,000, apply an additional 5% discount (should $10,000 and 5% be constants?)
- Discounts add together, so an employee spending $10,000 or more receives a 35% discount

## Output

- Total discount received, printed to two decimal places with an f-string
  - Output string: `"Discount Received: $"`
- Price after discount, printed to two decimal places with an f-string
  - Output string: `"New total: $"`

## Examples

```

Employee (e), member (m), or Enter to skip: E
Discount Received: $3.60
New total: $8.40
```

