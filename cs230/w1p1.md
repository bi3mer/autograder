# Week 1 - Problem 1: Purchase

Write a program that calculates the total cost of a purchase, including tax.

## Input

Prompt the user for two values:

- **price**: the price per item (a decimal number)
  - The prompt should be `"Enter price per item: "` (note the trailing space)
- **count**: the number of items purchased (a whole number)
  - The prompt should be `"Enter number of items: "` (note the trailing space)

## Processing

- Assume a fixed tax rate of **7.5%**.
- Calculate the **pre-tax cost**: price times count, **rounded to 2 decimal places**.
- Calculate the **tax paid**: pre-tax cost times the tax rate, **rounded to 2 decimal places**.
- Calculate the **after-tax cost**: pre-tax cost plus tax paid.
- Use the `round` function to round to two decimal places

## Output

Print all three values:

- Pre-tax cost
  - Output string: `"Pre-tax cost="`
- Tax paid
  - Output string: `"Tax paid="`
- After-tax cost
  - Output string: `"After-tax cost="`

Each line has a single space between the output string and the value, as shown in the example below.

## Example

```
Enter price per item: 10
Enter number of items: 3
Pre-tax cost= 30.0
Tax paid= 2.25
After-tax cost= 32.25
```
