# Week 4 - Problem 1: Date Validation

Ask the user for a date written as `YYYY/MM/DD`, like `2026/12/07`, and check every piece of it before you trust it. Once the user has entered a valid date, print it back in a new format, `YYYY-MM-DD`, with dashes in place of the slashes.

## Input

Prompt the user for one line:

- `"Enter a date (YYYY/MM/DD): "`

A valid answer has exactly three parts separated by `/`: a year, a month, and a day.

- The year is exactly 4 digits. Any year from `0000` to `9999` is fine.
- The month is exactly 2 digits, from `01` to `12`.
- The day is exactly 2 digits, from `01` to `28`. You do not need to know which months have 30 or 31 days: every month accepts `01` through `28` and nothing higher.

Anything else is invalid: letters, a missing part, a part with the wrong number of digits (`2026/1/7`), an extra `/` anywhere (`2026//12/07` or `2026/12/07/`), or a month or day out of range. If the answer is invalid, ask the same question again, as many times as it takes, until the answer is valid. You can assume the user presses Enter after each answer, and nothing else.

## Processing

- Loop until the user enters a valid date.
- Break the answer into parts with [`split()`](https://www.w3schools.com/python/ref_string_split.asp).
  - If you assign the output to a variable you can access elements with brackets (e.g. `split_date[0]`)
  - You can use `len` on output of `split` (e.g. `len(split_date)`)
- Use `len()` to check the number of digits in each part.
- Check each part with [`isdigit()`](https://www.w3schools.com/python/ref_string_isdigit.asp), which is `True` only when every character is a digit.
- Once every check passes, put the parts back together with [`join()`](https://www.w3schools.com/python/ref_string_join.asp).

## Output

Print the date with its parts joined by `-`:

- Output string: `"Date: "`

## Examples

```
Enter a date (YYYY/MM/DD): 2026/12/07
Date: 2026-12-07
```

The extra `/` makes four parts, so the first answer is rejected:

```
Enter a date (YYYY/MM/DD): 2026//12/07
Enter a date (YYYY/MM/DD): 2026/12/07
Date: 2026-12-07
```

`13` is not a month, and `2026/1/7` has the right values but the wrong number of digits:

```
Enter a date (YYYY/MM/DD): 2026/13/07
Enter a date (YYYY/MM/DD): 2026/1/7
Enter a date (YYYY/MM/DD): 2026/01/07
Date: 2026-01-07
```

`hello` has no `/` at all, and neither does `2026-12-07`, so each is a single part rather than three. Year `0000` is valid:

```
Enter a date (YYYY/MM/DD): hello
Enter a date (YYYY/MM/DD): 2026-12-07
Enter a date (YYYY/MM/DD): 0000/01/01
Date: 0000-01-01
```
