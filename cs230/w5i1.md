# Week 5 - In-Class Activity 1: Yes or No Function

In Week 3 you wrote a loop that asks "Yes or no?" until the user types `yes` or `no`. This time the loop goes inside a function named `yes_or_no`. Any program that needs a yes-or-no answer can then get one with a single call: the function asks, re-asks until the answer is valid, and hands back `True` for yes or `False` for no.

## Input

Inside `yes_or_no`, prompt the user with: `"Yes or no? "`

A valid answer is exactly `yes` or exactly `no`. Anything else is invalid, including `Yes`, `NO`, and `yes` with a space before or after it. If the answer is invalid, ask the same question again, as many times as it takes, until the answer is valid.

## Processing

- Define a function named `yes_or_no` that takes no arguments.
- Inside the function, loop until the user enters `yes` or `no`.
- Once the answer is valid, return `True` if the user entered `yes` and `False` if they entered `no`. `True` and `False` are Python's two boolean values, written without quotes.
- The function prints nothing. `return` hands the value back to the line that called the function, and that line decides what to do with it.

## Output

After the function, leave two blank lines (flake8 counts one as a finding), then end the program with this line, which calls the function and prints what it returns:

```python
print(yes_or_no())
```

Python prints the boolean values as `True` and `False`, so the last line of output is one of those two words.

## Examples

```
Yes or no? yes
True
```

```
Yes or no? no
False
```

Here the first three answers were invalid, so the question was asked again each time:

```
Yes or no? n
Yes or no? NO
Yes or no? I said no!
Yes or no? no
False
```

`maybe` is not an answer, and `Yes` has a capital letter:

```
Yes or no? maybe
Yes or no? Yes
Yes or no? yes
True
```
